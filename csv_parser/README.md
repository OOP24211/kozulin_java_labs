# CSV Parser

Проект на Java, предназначенный для обработки текстового файла,
подсчёта статистики слов и экспорта результата в CSV-файл.

## Возможности
- Поддержка всех языков из UTF-8
- Регистронезависимый подсчёт слов
- Запуск и управление через командную строку
- Экспорт результатов в формате CSV
- Сортировка слов по частоте (по убыванию)
